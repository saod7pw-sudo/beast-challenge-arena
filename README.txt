BEAST CHALLENGE ARENA — installable web app starter

This is a mobile-friendly 3D-style browser game prototype with:
- 5 computer-controlled rivals
- cash pickups and moving hazards
- keyboard and touch controls
- best score saved locally on the device
- offline app shell after first successful load

IMPORTANT:
This ZIP is a web app project, not an App Store-signed native iOS app.
To install it on iPhone:
1. Upload the contents of this folder to an HTTPS static host (for example, GitHub Pages or Netlify).
2. Open the hosted URL in Safari on your iPhone.
3. Tap Share -> Add to Home Screen.
4. Launch Beast Arena from the new Home Screen icon.

A real online multiplayer mode needs a hosted multiplayer server and matchmaking; this prototype currently uses computer-controlled rivals.
